# WhisperAnnote — Техническое задание (ТЗ)

**Дата:** 2026-06-01
**Версия:** 2.0
**Статус:** Проектирование

---

## 1. Наименование продукта

**WhisperAnnote 2.0** — десктопное приложение для автоматической транскрибации русскоязычных аудиозаписей совещаний с диаризацией спикеров.

---

## 2. Цель разработки

Создать замену устаревшему PyQt5-приложению WhisperAnnote 1.x (на базе Whisperer_GUI), объединив лучшие наработки трёх проектов:
- Whisperer_v1 (React-интерфейс, i18n)
- Whisperer_GUI + WhisperAnnote 1.x (пайплайн транскрибации + диаризации)
- WhisperLiveKit (FastAPI-архитектура, VAD)

Новая версия должна предоставлять современный интерфейс на Electron, поддерживать автоматическую пакетную обработку файлов из указанной папки и ориентироваться на русский язык.

---

## 3. Область применения

Транскрибация и диаризация записей:
- Рабочих совещаний и meeting-записей
- Интервью и подкастов
- Конференций и лекций
- Телефонных разговоров (колл-центры)

## 6. Архитектурные решения

### 6.1 Общая архитектура: трёхпроцессная модель

```
┌──────────────────────┐     IPC      ┌───────────────────────┐
│ Electron Main        │◄────────────►│ Electron Renderer     │
│ - Python manager     │              │ - React 18            │
│ - File watcher       │              │ - shadcn/ui           │
│ - Scheduler          │              │ - Tailwind            │
└──────────┬───────────┘              └───────────┬───────────┘
           │ child_process.spawn                  │ HTTP + WS
           ▼                                      ▼
┌──────────────────────────────────────────────────────────┐
│ Python FastAPI Backend (subprocess)                       │
│ - /api/transcribe  (разовая обработка)                    │
│ - /api/queue       (пакетная очередь)                     │
│ - /ws/progress     (прогресс в реальном времени)          │
│ - /api/health      (статус)                               │
└──────────────────────────────────────────────────────────┘
```

### 6.2 Конвейер обработки (5 шагов)

```
Входной файл (.mp4, .mp3, .wav, ...)
  → [1] ffmpeg: конвертация в MP3 128kbps
  → [2] ffmpeg: извлечение WAV 16kHz mono PCM
  → [3] pyannote: диаризация по полному аудио
  → [4] faster-whisper: транскрибация чанками по 300 сек (language=ru)
  → [5] Alignment: сопоставление сегментов со спикерами (midpoint lookup)
  → Вывод: JSON + TXT + SRT + DOCX
```

### 6.3 Ключевые зависимости

| Сторона | Зависимость | Назначение |
|---------|-------------|-----------|
| Electron main | chokidar | File watcher |
| Electron main | node-cron | Периодический запуск |
| Electron main | electron-store | Персистентный конфиг |
| Electron renderer | React 18 + TypeScript | UI |
| Electron renderer | Tailwind CSS 4 + shadcn/ui | Стилизация |
| Electron renderer | react-i18next | Интернационализация |
| Electron renderer | zustand | Менеджер состояния |
| Python backend | FastAPI + uvicorn | HTTP + WebSocket сервер |
| Python backend | faster-whisper | Транскрибация (CTranslate2) |
| Python backend | pyannote.audio | Диаризация |
| Python backend | torch + torchaudio | ML runtime |
| Система | FFmpeg | Аудио-конвертация |

## 9. Критерии приёмки

- [ ] Приложение запускается на Windows 10/11
- [ ] Drag-and-drop одного аудиофайла приводит к успешной транскрибации с диаризацией
- [ ] В результатах каждый сегмент имеет метку спикера и таймстемп
- [ ] Экспорт работает во всех 4 форматах (JSON, TXT, SRT, DOCX)
- [ ] Автообработка папки: появление нового файла → автоматическая транскрибация
- [ ] Переключение тёмной/светлой темы работает без перезагрузки
- [ ] Русский интерфейс отображается корректно без кракозябр
- [ ] При отсутствии FFmpeg выводится понятное сообщение об ошибке
- [ ] При неверном HF-токене выводится инструкция по получению

## 10. Отличия от версии 1.x

| Параметр | WhisperAnnote 1.x | WhisperAnnote 2.0 |
|----------|-------------------|-------------------|
| Интерфейс | PyQt5 (устаревший) | Electron + React (современный) |
| Транскрибация | openai-whisper | faster-whisper (CTranslate2, 4x быстрее) |
| Автообработка | Нет | Да (file watcher + cron) |
| Конвертация в MP3 | Нет | Да (стандартизация входных данных) |
| Экспорт DOCX | Нет | Да |
| Интернационализация | Только RU | RU + EN |
| Тема | Только тёмная | Тёмная + светлая |
| Сборка | Запуск из исходников | electron-builder инсталлятор |
| Архитектура | Монолит (GUI + ML в одном процессе) | Трёхпроцессная (Main + Renderer + Python) |
| WebSocket прогресс | Нет (poll-based) | Да (real-time streaming) |
